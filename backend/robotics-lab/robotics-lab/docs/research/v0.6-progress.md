- `tools/audit_torque_mpc.py` (output `docs/research/v0.6-mpc-audit.json`), all explicit outcomes:
  - documented objective vs assembled QP (random z pairs, constant cancels): 2.5e-13 relative (full size,
    875 vars / 1575 rows), ~1e-14 on the small case;
  - 1-joint N=2 hand case (states eliminated by hand, 2x2 normal equations): first torque equal to 1e-12;
    with an active torque limit (3.2 Nm < unconstrained 3.28) equal to a bounded search (7e-8);
    with d_hat = 1 Nm equal as well (so B d_hat and hold = tau_g - d_hat are consistent);
  - constraint rows: dynamics residual 2.6e-15; torque rows = tau/tau_scale; state rows x+s, x-s, s;
    q bounds on q entries, velocity bounds (with margin) on qd entries; torque bounds = actuator limits;
  - disturbance signs: feedthrough subtracts (d_now - d_update) exactly; on the plant a constant
    unmeasured qfrc_applied torque is estimated with the same sign to 3e-13 Nm;
  - prediction vs nonlinear rollouts (default task, mid-motion): 1 interval 2e-9..2e-8 rad (c exact at the
    linearization point); over the 0.5 s horizon 1.6e-3..5.3e-3 rad; re-linearizing at each step removes it
    (<= 2e-8). Conclusion: the horizon error is the documented frozen-Jacobian (LTI) approximation, not a bug.
  - statuses on the wall demo: 450/450 "solved", 0 fallbacks, primal residual max 2.7e-9, dual 7.5e-5,
    max 175 iterations. "solved inaccurate" is accepted (counted in stats as `inaccurate`), every other
    status or a non-finite solution hands over to CTC until the next successful update.

### M2 — physical pick-and-place (done)

- Gripper probe: Menagerie actuator8 is a 100 N/m servo on the finger tendon -> 2.5 N squeeze on a
  50 mm box (holds ~0.25 kg at friction 1). Opt-in `robot.gripper_stiffness` 1500 N/m (damping 20)
  -> ~37 N squeeze (real Franka Hand: 70 N continuous). Same actuator, ctrl and force range.
- Scenes `environments/pick_place.xml`, `pick_place_obstacle.xml` (free 50x50x60 mm box; obstacle
  x 0.42-0.58, y +-0.02, z to 0.58). Overrides now accept geom mass / friction.
- Pose IK (`ArmKinematics.solve_pose_ik`, world-frame rotation vector, 6x7 Jacobian); rotational
  Jacobian = finite differences to 6e-10; `solve_ik` unchanged.
- Cartesian lines (`tasks/pick_place.py`): dense pose IK + spline + quintic; validated along the
  timed spline: < 0.05 mm from the line, < 0.07 deg orientation error.
- Checker additions (opt-in): fixed non-arm qpos, allowed pair rules, rigid attachment of the
  object in the private model with lever arms grown by its extent.
- Controller model boundary: `engine.contact_free_model()` (contacts off, nominal object mass);
  test shows ID / gravity / prediction c identical across payload masses 0.15/1.15 kg and object
  contact states; control test shows the default model (contacts on) would see the grip.
- Decision: plant contact solver `cone: elliptic, impratio: 10`. Default pyramidal cone let the
  0.4 kg box creep ~5 mm through the grasp (1.0 kg: > 6 mm, failed); elliptic+impratio 10: < 1 mm.
  To be re-checked in the M3 sensitivity check.
- Bugs found and fixed during bring-up: lowering used the transport-start grasp offset (object had
  slipped -> line into the table); release ended before the fingers were fully open (retreat check
  4.8 mm < 5 mm); release-during-transport fault restarted the segment (ref jump).
- Dev results (`results/v0.6/dev_ctc.json`, `dev_mpc.json`): 5/5 CTC+observer, 5/5 torque MPC+observer
  (0 fallback steps, all updates "solved"), 0 forbidden contacts, placement error 0.1-2.4 mm.
- Negative controls (dev_free_1): skip_close -> close (80 mm width); weak_grip (Menagerie gains,
  1 kg) -> lift (rose -0.1 mm); place_offset 30 mm -> verify (29.9 mm); release_during_transport ->
  transport (dropped). low_friction was dropped as a control: MuJoCo uses the larger friction of the
  two geoms, so lowering only the object's friction had no effect (it succeeded).
- Mass choice for M3: 0.15 / 0.40 / 1.15 kg (plastic, aluminium, steel block of this size); dev probe
  at 1.0 and 1.5 kg succeeded with all four configurations (observer: 4.5 -> 0.3 mm ee error, CTC).
- Tests: tests/test_pick_place.py 14 passed; full suite 209 passed (100 s); wall demo unchanged.
