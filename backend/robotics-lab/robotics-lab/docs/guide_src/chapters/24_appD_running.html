Running the project

All commands are for Windows PowerShell from the repository root, calling the virtual environment's Python directly. The status column distinguishes commands that were run on commit 5dbeffd (during the v0.5.2 milestone or while preparing this guide, 19 Oct 2026) from commands that are only code-verified: the options exist in the argument parser and the code path was read, but the command was not executed for this guide.

Set-up

py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt     # mujoco 3.16.0, numpy, scipy, osqp, PyYAML, pytest, matplotlib

Status: from the README; the environment used here already existed (not re-created for this guide).

Rebuilding this guide

.\.venv\Scripts\python.exe docs\guide_src\make_figures.py      # computed figures (fast)            [run]
.\.venv\Scripts\python.exe docs\guide_src\build_guide.py       # HTML -> PDF via headless Chrome    [run]

The build needs Chrome or Edge and the websockets package (already in the venv). pypdf is optional (it fills the page numbers in the table of contents); it is not in requirements.txt. MathJax is vendored in docs/guide_src/vendor/, so no network access is needed.
