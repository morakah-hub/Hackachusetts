Glossary

Plain-language definitions of the terms used in this guide, alphabetically.

Actuator
The model of a motor at a joint. Converts a command into a joint torque. Here either a position servo or a torque motor.
ADMM
Alternating Direction Method of Multipliers: the iterative algorithm inside OSQP; alternates a linear solve with a projection onto the constraints.
Armature
Extra inertia added to a joint to represent the motor rotor and gearbox (0.1 kg·m² per Panda joint in the model).
Broadphase / midphase / narrowphase
Stages of collision detection: cheap bounding-box culling of pairs, culling inside multi-geom bodies, and the exact shape-pair computation.
C-space (configuration space)
The space of all joint-angle vectors; for the Panda arm a 7-D box. Each point is one posture.
C-obstacle
The set of configurations in which the robot touches an obstacle.
Clearance
The minimum distance between the robot and the environment; the planner requires 20 mm at checked configurations.
Closed loop / feedback
Control that uses measurements of what actually happened to compute the next command.
Computed-torque control (CTC)
Control that computes the torque for a desired acceleration with the robot's inverse dynamics plus PD feedback.
Configuration
The vector of joint angles $q$; it fixes the pose of every link.
Constraint (hard / soft)
A limit the optimizer must respect exactly (hard) or may violate at a heavy penalty (soft, via slack variables).
Contact margin
A distance below which MuJoCo already reports a contact; used by the checker to implement clearance.
Convex (problem)
An optimization problem whose every local minimum is global; quadratic programs with positive semidefinite cost are convex.
Coriolis / centrifugal torques
Velocity-dependent torques arising from motion in rotating frames; the $C(q,\dot q)\dot q$ term.
Degree of freedom (DOF)
An independent way a system can move.
Damped least squares (DLS)
An IK step $J^T(JJ^T+\lambda^2I)^{-1}e$ that stays bounded near singularities.
Deadline overrun
An MPC update that took longer (wall clock) than its control period (20 ms).
Discretization
Turning a continuous-time model into a map from one sampling instant to the next.
Disturbance observer
An estimator of unknown torques from measured motion and applied torque; makes control offset-free.
Double-S profile
A jerk-limited, time-optimal rest-to-rest timing law with seven constant-jerk phases.
Edge
A straight joint-space segment between two configurations; checked by sampling.
End effector (EE)
The robot's working point; here a site between the fingertips.
Episode
One complete run of an experiment condition.
Exact penalty
A linear slack penalty large enough that soft constraints behave like hard ones whenever possible.
Feedforward
The part of a command computed from the reference in advance, not from the error.
Forward kinematics (FK)
Computing the hand pose from joint angles.
Gravity compensation
The torque that holds the arm still against gravity, $g(q)$.
GJK / EPA
Algorithms for the distance (GJK) and penetration depth (EPA) between convex shapes.
Homogeneous transformation
A 4×4 matrix combining rotation and translation of a frame.
Horizon (prediction)
How many steps ahead the MPC predicts; $N$ = 25 steps = 0.5 s for the torque MPC.
Implicitfast
MuJoCo's integrator that treats velocity-dependent forces implicitly, stable for stiff damping.
Inertia (mass) matrix $M(q)$
The posture-dependent matrix relating joint accelerations to the torques that produce them.
Inverse dynamics
Computing the torque needed for a given acceleration (mj_inverse).
Inverse kinematics (IK)
Finding joint angles that place the hand at a desired position.
Jacobian
The matrix mapping joint velocities to hand velocity, $\dot x = J\dot q$.
Jerk
The time derivative of acceleration.
Lever arm $R_j$
An upper bound on the distance from joint $j$'s axis to any robot geometry it moves; bounds how far points move.
Linearization
Approximating a nonlinear map by a linear (affine) one near an operating point.
Linear MPC
MPC with a linear prediction model, giving a convex QP.
Mocap body
A MuJoCo body moved kinematically by code; here the visual target marker.
Model mismatch
A difference between the controller's model and the plant (tested by scaling masses).
MPC (model predictive control)
Control by repeatedly solving a finite-horizon optimization with a model and applying the first command.
MuJoCo
The physics engine simulating the robot (version 3.16).
Null space
Joint motions that do not move the hand; used to steer a redundant arm's posture.
Offset-free control
Control without steady-state error under constant disturbances.
OSQP
The quadratic-programming solver used by both MPCs.
Path / trajectory
A geometric route (no time) / a route with timing $q(t)$.
PID
Proportional–integral–derivative feedback control.
Plant
The system being controlled: the simulated Panda.
Polishing
An OSQP step that refines an approximate solution to high accuracy.
Position servo
An actuator that pulls a joint towards a commanded angle with a stiff spring-damper.
Probabilistic completeness
The property that the chance of finding an existing path tends to 1 as sampling continues.
Quadratic program (QP)
Minimize a quadratic cost subject to linear constraints.
Quintic (minimum-jerk) profile
The timing law $10\tau^3 - 15\tau^4 + 6\tau^5$.
Receding horizon
Re-planning at every step over a window that moves forward with time.
Redundancy
Having more DOF than the task needs (7 joints for a 3-D position goal).
Reference
The desired trajectory the controller tracks.
RRT / RRT-Connect
Rapidly-exploring random tree planners; RRT-Connect grows two trees and joins them.
Seed
A number fixing a random generator so runs are reproducible.
Shortcutting
Shortening a planned path by replacing parts with valid straight edges.
Singularity
A posture where the Jacobian loses rank and some hand directions are unreachable instantaneously.
Slack variable
An extra variable that measures (and lets the optimizer pay for) a constraint violation.
State
The variables that determine future motion: $x = (q, \dot q)$.
Torque motor
An actuator that applies exactly the commanded torque (within limits).
Tracking error
Reference minus actual; the main controller quality metric.
Via point
An intermediate waypoint of a planned path; the reference stops there without holding.
Warm start
Starting an iterative solver from a previous solution to save iterations.
Workspace
The set of hand positions the robot can reach.
World model
The robot's belief about its surroundings (implicit here: the MuJoCo model).
Zero-order hold
Holding a command constant between sampling instants.
